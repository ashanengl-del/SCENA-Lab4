# СЦЕНА

«СЦЕНА» — аналітична інформаційна система концертної агенції. Цей репозиторій створено для лабораторної роботи № 4 з дисципліни «Інформаційні системи».

## Демонстраційна сторінка

Файл [index.html](index.html) містить перелік показників концертної агенції та приклад звіту про продаж квитків. У таблиці наведено умовні дані про кількість проданих квитків і місткість залів.

Щоб переглянути сторінку, збережіть index.html і відкрийте його у браузері.

## Історія розробки

У гілці main збережено базову версію сторінки. Гілка feature містить розділ із розрахунком заповнюваності залів. Pull Request #1 додав цей розділ до main, а Pull Request #2 скасував зміни першого об’єднання.
